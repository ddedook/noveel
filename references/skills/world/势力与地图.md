# 势力与地图

势力提供资源与压力；地图升级必须改变行动规则。读者向：规则能约束行动，非百科。

## 核心原则

1. 势力必须有目标、资源、代表人物，不能只有名字。
2. 换地图带走旧伏笔、旧敌人或旧情感资产至少一项。
3. 地位升高时，危险与对手量级同步升高。
4. **落库为世界树节点**：`name` + **`kind`** + detail；人物归属用节点名填 `faction`。

## kind 分组（写入时选合法 kind）

- **宇宙/界域**：universe、multiverse、galaxy、realm、domain、plane…
- **地理**：planet、continent、region、mountain、secret_realm…
- **政区与聚落**：country、empire、kingdom、city、town、settlement…
- **组织与势力**：faction、sect、clan、guild、army、corporation、alliance、cult、academy…
- **其他**：custom（须在 detail 说清类型）

## 父子挂载（硬约束，写库会校验）

同批创建先父后子；父节点须已存在或同批先写。用 `parentId` / `parentName` 挂父。

| 子 kind | 典型父级 | 禁止 |
|---------|----------|------|
| universe / multiverse / custom | 可无父（根） | — |
| city / town / settlement | country、region、empire、kingdom、federation、mainland、continent… | 无父挂根；直接挂 universe |
| faction / sect / guild / clan… | city、town、settlement、country… | 无父挂根；跨层挂宇宙 |

层差过大（如势力直接挂宇宙）会被拒绝；请先建地理/政区再挂组织。

## detail 四栏

固定结构优先填：`geography` / `culture` / `history` / `factions`（再加模板扩展字段）。规则约束写进能约束行动的栏，勿只堆风景。

## 可执行清单

### 势力（组织类 kind）

1. 当前最想得到什么。
2. 资源：钱/武力/情报/人脉/地盘/制度/技术。
3. 内部矛盾与外部对手。
4. 与主角关系：加入/利用/反抗/追杀/继承因果。
5. 代表人物须已有或同步建 `role`；人物 `faction` = 本节点名。

### 地图（地理/政区类 kind）

1. 进入/离开条件；环境规则与危险。
2. 新地图带来：新角色、新规则、新目标、新冲突。
3. 与旧地图关联；换地图前旧冲突阶段性收束。
4. 重大易主/战乱写 `worldTimeline`。

## 禁忌

- 连续刷同类势力打脸事件无节奏变化。
- 只改地名，行动规则不变。
- 势力登场不推动任何核心事件。
- `kind` 乱填或人物 `faction` 指向未建档节点。
