# 阶段 0 — Adler 整书理解（文风）

## 目标

建立对源作**文风骨架**的共识，产出 `STYLE_OVERVIEW.md`。

## 步骤

1. 分块阅读全文（或代表性长样本，建议 ≥3 万字；不足则在 overview 中标注置信度低）。
2. 按 Adler 四步分析，但问题换成文风：
   - **结构**: 人称/视角、章节节奏、叙述密度
   - **解释**: 语域（文言/白话/网文口语）、标志句式、情绪表达方式
   - **批判**: 作者习惯的盲点、易被模仿翻车的点
   - **应用**: 哪些场景最适合套用此风格（战斗、言情、日常、推理…）
3. 填充 overview，至少包含：
   - 一句话风格标签
   - 视角与人称
   - 语域与节奏气质（3–5 词）
   - 标志性手法（3–7 条）
   - 明显忌讳（3–5 条）
   - 建议 slug / name / author / source_title

## 轻确认

展示 overview：「骨架对吗？要强调或弱化哪些手法？」确认后再进阶段 1。应用内可自动继续。
